## Active Project — DCF

**Data Collector Framework** · `v0.2.0` · Active Development

A lightweight, module-independent ABAP OO framework built around a single principle:
*collect data once, use it anywhere.*

DCF separates data collection from data consumption — cleanly, automatically, and without boilerplate.
It works across the entire ABAP stack: programs, classes, BAdIs, function modules, and print environments alike.
The consuming layer declares what it needs. The framework handles the rest.

*Facade · Strategy · Template Method · Factory · Auto-Discovery · Dependency Injection · Dependency Resolution · Chain of Responsibility · Proxy · Null Object · Observer · Composite*
